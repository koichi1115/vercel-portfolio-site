# API監視ダッシュボード

## プロジェクト概要

マイクロサービスアーキテクチャで構成されたシステムのAPI監視とパフォーマンスモニタリングを行うリアルタイムダッシュボードです。

複数のAPIエンドポイントの稼働状況、レスポンスタイム、エラー率などを一元的に可視化し、問題の早期発見と迅速な対応を可能にします。

## 主な機能

### リアルタイムモニタリング
- **ライブステータス**: WebSocketによるリアルタイムステータス更新
- **レスポンスタイム**: ミリ秒単位でのレスポンスタイム計測
- **エラーレート**: HTTPステータスコード別のエラー率表示
- **スループット**: 秒間リクエスト数（RPS）の可視化

### アラート機能
- **閾値ベースアラート**: レスポンスタイムやエラー率の閾値超過時に通知
- **カスタムアラートルール**: 複雑な条件を組み合わせたアラート設定
- **通知チャネル**: Slack、Email、Webhookでの通知
- **アラート履歴**: 過去のアラート発生履歴の確認

### ダッシュボードカスタマイズ
- **ドラッグ&ドロップ**: ウィジェットの自由な配置
- **複数ダッシュボード**: 用途別の複数ダッシュボード作成
- **共有機能**: チーム内でのダッシュボード共有
- **ダークモード**: 目に優しいダークテーマ

### データ分析
- **時系列グラフ**: Chart.jsによる美しいグラフ表示
- **期間指定**: 任意の期間でのデータ分析
- **比較機能**: 異なる期間やエンドポイントの比較
- **エクスポート**: CSV、PNG形式でのデータエクスポート

## 技術スタック

### フロントエンド
- **Vue.js 3**: Composition APIを活用した保守性の高いコード
- **TypeScript**: 型安全な開発
- **Vite**: 高速なビルドツール
- **Chart.js**: データ可視化ライブラリ
- **Pinia**: 状態管理

### バックエンド
- **FastAPI**: 高速なPython Webフレームワーク
- **Prometheus**: メトリクス収集
- **Redis**: リアルタイムデータのキャッシング
- **WebSocket**: リアルタイム通信

## 技術的な挑戦

### パフォーマンス最適化
数百のAPIエンドポイントを監視する際のパフォーマンス最適化が課題でした。以下の対策を実施：

- **仮想スクロール**: 大量のデータを効率的に表示
- **データサンプリング**: グラフ描画時のデータポイント削減
- **WebWorker**: 重い計算処理のバックグラウンド実行
- **差分更新**: 変更があった部分のみ再レンダリング

### リアルタイムデータ処理
WebSocketを使用した大量のリアルタイムデータの処理と表示を実装。バックプレッシャー制御を導入し、クライアント側の負荷を軽減しました。

### スケーラビリティ
Redisを活用したデータキャッシングと、Prometheusによる効率的なメトリクス収集により、大規模システムにも対応できる設計としました。

## 成果

- 監視対象API: 300+エンドポイント
- 障害検知時間: 平均30秒以内
- ダッシュボード利用ユーザー: 50名（開発・運用チーム）
- インシデント解決時間: 40%短縮

## 学んだこと

リアルタイムデータの可視化において、パフォーマンスとユーザー体験のバランスが重要であることを学びました。特に、大量のデータを扱う際のメモリ管理と描画最適化の知見を深めることができました。

また、運用チームとの密なコミュニケーションにより、実際に役立つ機能を優先的に実装できたことも、プロダクト開発における重要な学びとなりました。

# AIタスク管理アプリ

## プロジェクト概要

Gemini APIを統合したインテリジェントなタスク管理アプリケーションです。自然言語でのタスク登録や、AIによる優先順位の自動提案など、従来のタスク管理アプリにはない機能を実装しました。

## 主な機能

### AIアシスタント機能
- **自然言語タスク登録**: 「明日の午後3時にミーティング」のような自然な表現でタスクを登録
- **優先順位の自動提案**: タスクの内容と期限から優先順位をAIが提案
- **タスク分解**: 大きなタスクを小さなサブタスクに自動分解
- **スマートリマインダー**: コンテキストを考慮した最適なタイミングでの通知

### タスク管理機能
- **カンバンビュー**: ドラッグ&ドロップでタスクを移動
- **カレンダービュー**: 期限ベースのタスク表示
- **フィルター・検索**: タグ、優先度、期限でのフィルタリング
- **進捗トラッキング**: プロジェクトごとの進捗率表示

### データ管理
- **リアルタイム同期**: 複数デバイス間でのリアルタイム同期
- **オフライン対応**: Service Workerによるオフライン機能
- **データエクスポート**: CSV、JSONフォーマットでのエクスポート

## 技術スタック

### フロントエンド
- **React + TypeScript**: 型安全な開発環境
- **Tailwind CSS**: モダンなUI設計
- **React Query**: サーバーステートの効率的な管理
- **Zustand**: クライアントステートの軽量管理

### バックエンド
- **Node.js + Express**: RESTful API
- **MongoDB**: ドキュメント指向データベース
- **Gemini API**: AI機能の実装
- **JWT**: セキュアな認証

## 技術的な挑戦

### AI統合
Gemini APIのプロンプトエンジニアリングに時間をかけ、ユーザーの意図を正確に理解できるように調整しました。特に、日本語の曖昧な表現を適切に解釈するための工夫を行いました。

### パフォーマンス最適化
- React Queryによる積極的なキャッシング
- 仮想スクロールによる大量タスクの高速表示
- 画像の遅延読み込み

### リアルタイム同期
WebSocketを使用した複数デバイス間のリアルタイム同期を実装。競合解決のロジックも組み込みました。

## 成果

- ユーザー数: 500名突破（β版）
- タスク登録時間: 従来比50%短縮
- ユーザー満足度: 4.5/5.0
- 日次アクティブユーザー: 200名

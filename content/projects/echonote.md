# EchoNote（エコーノート）

**声が反響し、ノートになる。** 録音するだけで、根拠付きの高精度ノートが完成するiOSアプリです。

## 解決する課題

- 会議や講演でメモを取りながら聞くと、内容を聞き逃す
- 録音はしたが、後から文字起こしを読み返すのが面倒
- 「あれ何だっけ？」が頻発し、期限のあるタスクを見落とす

## コア機能

### 1. ワンタップ録音
60分以上の長時間録音に対応。バックグラウンドでも途切れません。

### 2. 資料スキャン & 用語抽出
配布資料をカメラでスキャン → AIが専門用語を自動抽出 → 文字起こし精度を向上。

### 3. AI補正 & エビデンス付きノート生成
音声認識の誤りをAIが自動補正。構造化ノートを生成し、全ての記述に元発話の根拠（タイムスタンプ・引用）を付与。

### 4. レビューキュー
信頼度の低い箇所をAIが自動検出。全文を読み返さず、要確認ポイントだけを効率的にレビュー。

### 5. TODO自動抽出
ノートからアクションアイテムを自動抽出。期限・担当者も検出。

### 6. まとめ資料生成
ノートを「LP形式」「参考書形式」などのテンプレートで高品質PDFに自動変換。

## 用語メモリ（セッション横断学習）

同じトピックの録音を重ねるごとに、AIが専門用語を学習。2回目以降のセッションでは補正精度が格段にアップします。

## 技術スタック

| レイヤー | 技術 |
|---------|------|
| アプリ | React Native (Expo) + TypeScript |
| 状態管理 | Zustand + AsyncStorage |
| 音声認識 | xAI Grok STT (バッチ $0.10/hr) |
| AI補正・ノート生成 | Anthropic Claude (Haiku / Sonnet) |
| OCR | Claude Vision |
| バックエンド | Cloudflare Workers |
